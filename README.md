# Sudoku Game
A web-based Sudoku application featuring mathematician Arto Inkala’s well-known puzzle, considered to be one of the world’s hardest solvable Sudokus. The application is designed with a game-oriented and user-friendly interface, including features such as note-taking, hints, and an interactive UI with visual feedback.

# Features
- Note-taking system
- Hint functionality
- Interactive UI with visual feedback
- Responsive game-oriented design

# Technologies
- HTML
- CSS
- JavaScript
